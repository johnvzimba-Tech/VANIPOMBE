# VANIPOMBE Free Download Website

This is a GitHub Pages-ready website for distributing the VANIPOMBE Android APK without Google Play.

## Folder structure

    index.html
    style.css
    apk/
        VANIPOMBE.apk

## Important

The website is ready, but the actual APK binary is not included yet because an Android APK must be built from the Android Studio project and tested before it is distributed.

After you have the final APK, rename it exactly:

    VANIPOMBE.apk

and place it inside:

    apk/

The Download button already points to that file.

## Free hosting

GitHub Pages can host this site from a public GitHub repository.

Typical URL:

    https://YOUR-GITHUB-USERNAME.github.io/VANIPOMBE/

## Publishing

1. Create a public GitHub repository named VANIPOMBE.
2. Upload index.html, style.css and the apk folder.
3. Go to Settings > Pages.
4. Select "Deploy from a branch".
5. Select the main branch and the root folder.
6. Save.
7. GitHub will provide the website URL.

Do not upload passwords, signing keys, or private certificates to the repository.

## Android installation

Users download the APK from the website and install it on Android. Because this is outside Google Play, Android may display a security warning or require permission to install from that source.
